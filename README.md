# Signal Processing & Mathematical Modeling 📊

### 🚀 Overview
This repository hosts a collection of algorithms and scripts for signal analysis, system modeling, and data visualization. Developed using **MATLAB**, it focuses on mathematical implementation of complex engineering problems.

### 🛠️ Key Concepts & Algorithms
* **Signal Analysis:** Implementation of noise reduction filters and signal reconstruction.
* **Fourier Transforms:** Frequency domain analysis using FFT (Fast Fourier Transform).
* **System Modeling:** Simulation of continuous and discrete systems.
* **Matrix Operations:** Optimized linear algebra calculations for large datasets.

### 💻 Tech Stack
* **Language:** MATLAB
* **Libraries:** Signal Processing Toolbox

### 🎓 Context
Developed as part of the academic coursework for the *Signal Processing* degree subject at the **University of Salamanca (USAL)**.
